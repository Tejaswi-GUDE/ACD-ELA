# Finite Automata — C++

A simple C++ implementation of **Finite Automata** concepts for the Automata and Compiler Design course.

## Programs

* **`dfa.cpp`** — DFA visualization and simulation
* **`nfa.cpp`** — NFA visualization and transition representation
* **`nfa-dfa.cpp`** — NFA to DFA conversion using **Subset Construction**

## Concepts Covered

* Deterministic Finite Automaton (DFA)
* Non-Deterministic Finite Automaton (NFA)
* States and transitions
* Start and final states
* NFA → DFA conversion
* Subset Construction
